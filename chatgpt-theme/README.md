# Emerald Grove for ChatGPT / Codex

Emerald Grove and Verdant Dawn as themes for the ChatGPT / Codex app.

| File                | Theme         | Variant |
| ------------------- | ------------- | ------- |
| `emerald-grove.txt` | Emerald Grove | dark    |
| `verdant-dawn.txt`  | Verdant Dawn  | light   |

## Installation

Copy the full contents of a file, including the `codex-theme-v1:` prefix, and import it in the app's appearance settings.

## Colors

The values are taken from the VS Code themes in [`../themes`](../themes).

| Setting       | Emerald Grove | Verdant Dawn | Source in the VS Code theme |
